# PWR1 R1 run note (2026-11-12, micas-lapserv1)

PWR1 measures the one-core cluster's dynamic energy on `dot3_w16` (dot_3, W = 16, N = 2048) per program section. This round builds part 1 of `pixi run cluster pwr <point>` (`cluster/power.py`): the quiet build (`sw/forge_quiet.elf`, snax-forge D135) on the netlist with our own vsim command and do-file, a VCD of the cluster's design scopes, one window per section from `obs_o`'s marks, one cut pass, one checked SAIF per window, packed under `pwr/` of `sim/runs/cluster/nangate45/dot3_w16.zip`. PT is R2, the energy report R3.

**Result:** `cluster pwr dot3_w16 (part 1): PASS, span marks 1–6 = 901 cycles in 6 windows, VCD 0.22 GB, 6 SAIFs checked`. Every window's cycles equal CORE1 R2's quiet run on the RTL. All six SAIFs pass X9: 923,145 driven nets, 513,914 at Z (DC's cut-loose port bits, PT6), `clk_i` TC = 2 × cycles. The committed code (`22db4358`) is the code of the reported run; a first run at `bc10dee8` (with the busy pins, since removed) gave the same windows, counts and SAIFs (`4_acc_config`'s byte for byte but its `DATE`).

## The step

`cluster/power.py` (wired into `cluster.py`'s `main`; its docstring holds the steps), reusing `cluster.py`'s `check_repos`, `image_id`, `Steps`, `unpack`, `rtl_changes`, `swap_check`, `questa_version`, `drop_wlf`, and `sim/pwr.py`'s `scopes`, `vcd_windows`, `saif_check`, `cell_model`, `tool`, `run_tool`. Part 1 is `part1()`; R2 can skip it when `pwr/check.json` is PASS.

- **Setup and build** as `gls`: the bundle and netlist unpacked in `tmp/cluster/dot3_w16/`, `rtl-gen`, clustergen, `mem.make` (its `tc_sram_impl.sv` equal to step 1's), `vsim_preparation` (image) and `snax-forge-sim` (host) with `gls`'s options. The build is checked as `gls`'s swap: the wrapper and 2,392 netlist modules from `work-vsim/gls`, 54 cells, `+initreg+0`, `+acc=n`, no `[tc_sram_impl]` print.
- **The vsim command** (`pwr/vsim_cmd.sh`): `bin/snitch_cluster.vsim` with its one `-do "log -r /*; run -a"` replaced by `-do <work>/pwr/pwr.do`, `-batch` for `$3`, the quiet ELF's realpath for `$(realpath $1)`, `++` for `++$2`; each must occur once or the step fails. Run from `target/snitch_cluster`, output in `pwr/vsim.txt`. Questa warns `-c and -batch are mutually exclusive` as in `snax-forge-run`.
- **The do-file** (`pwr/pwr.do`): `onbreak {resume}`, `onfinish stop`, `vcd file`, `source pwr/vcd_add.do`, a `when` on `/tb_bin/i_dut/i_snax_forge_cluster/obs_o` writing `<ps> <value>` per change to `pwr/obs_log.txt` (flushed) and at mark 7 `vcd off`, `vcd flush`; `run -all`, `quit -f`. No `log`, no `power`.
- **`vcd_add.do`**: 2,389 non-recursive `vcd add`, the wrapper's own nets then each of `pwr.scopes`' 2,388 design scopes (907 with escaped identifiers), each path in braces with its `/*`.
- **The windows** from `obs_log.txt` (in order, each once, from 1 to the check's mark), section k from t_k − 250 ps to t_{k+1} − 250 ps, cycles (t_{k+1} − t_k) / 1000, whole; against CORE1 R2's cycles (stop beyond 10 %).
- **The cut**: one `vcd_windows` pass, with two new optional arguments in `sim/pwr.py`: `timescale_10ps` (the VCD's `$timescale` must be 1ps, on one line or three; the cuts get `$timescale 10ps $end`, the time numbers unchanged) and `done` (called when a cut closes, so each window's vcd2saif starts at once). Default off; the other sources are unchanged. `dut.vcd` is deleted right after the pass.
- **vcd2saif** per window, `-instance tb_bin/i_dut/i_snax_forge_cluster -time t0 t1`, at most min(nproc, windows) = 6 jobs, no more cuts on disk than jobs, each cut deleted after its job; then `pwr.saif_check(saif, cycles, "clk_i")`.
- **Packed**: `pwr/` of `sim/runs/cluster/nangate45/dot3_w16.zip`, 24 members: `pwr.do`, `vcd_add.do`, `vsim_cmd.sh`, `vsim.txt`, `obs_log.txt`, `windows.json`, per window `w.saif` and `vcd2saif.log`, `logs/` (5 step logs), `check.json`. The zip's `rtl/` and `gls/` kept.

Tests (`cluster/test_power.py`, 12, pass; `pixi run arc-test` passes): the windows (in order, boot values and a same-step glitch skipped, the check's mark ending the span, a mark missing, repeated or early, the log ending before the check, a non-integer cycle count), the comparison with CORE1 R2, the `-do` replacement on a copy of the real `bin/snitch_cluster.vsim` (once; absent or twice fails), the `vcd add` lines and path components for escaped scopes, `vcd_windows` with the 10 ps timescale on a hand-written VCD (one-line, three-line and `1 ps` headers, the cut's times unchanged, `1ns` and `10ps` VCDs refused, the default unchanged), a boundary event refused, and the program-output filter.

### The nets at Z

513,914 entries in every window are at Z for the whole window: sub-design port bits that DC's boundary optimization cut loose (outputs nothing loads, inputs tied constant), mostly AXI data ports of the two crossbars (`mst_reqs_o[][w][data][]` 13,120, `mst_resps_i[][r][data][]` 12,160, …), the interconnect's read-only `io_tcdmReqs_*_bits_data` (2,112 per input), the streamers' `data_i`/`data_o`, and the top's `SYNOPSYS_UNCONNECTED__*`. By instance: `sparse_interconnect_i` 85,800, `i_axi_dma_xbar` 50,030, `i_cluster_xbar` 19,218. They are PT6's case: PT has no net behind them. X9 counts them apart.

### X in the DMA windows

X66 is kept (the macro models start X, no `SRAM_INIT_ZERO`). Nets with X time per window: 104,919, 3,156, 2,708, 2,708, 2,708, 96,751. The sources:

- window 1 (`dma load_A`): the banks' read data before any read. `snax_tcdm_rsp[*][p][data]` (2,048 bits at the wrapper) is X for 15.5 % of the window; the interconnect (10,528 nets in `sparse_interconnect_i`), the DMA's interconnect and the AXI-to-memory response buffers carry it on.
- window 6 (`dma store_out`): `wide_out_req_o[w][data]`'s unfilled byte lanes: 448 of 512 bits X for 71 % of the window (the DMA stores one word).
- every window: about 2,700 nets (1,971 to 2,068 X for the whole window), in core 0's request-response isolation and response FIFOs, the DMA's AXI-to-memory buffer and the TCDM muxes; 737 of them in the run window also hold 0 and 1.

X stands for a value that holds still here, so a window misses at most one toggle per net leaving X (vcd2saif counts only changes between 0 and 1), the size of VS1. In window 1, 91,247 of the 104,919 X nets hold X and one value with TC 0, and in window 6 92,233 of 96,751; 13,672 and 4,518 hold X, 0 and 1 and toggle (TC up to 253 in window 1, 1 in window 6), and for those the SAIF does not say how often they leave X (PITFALLS VS2).

## Drafts this round leans on

- X73 (windows): one window per program section from `obs_o`'s marks, from the first mark up to the check's (marks 1 to 6 on dot_3; the boot and the check left out), each from a quarter cycle before its mark's edge to a quarter cycle before the next's. The windows come from `obs_o` only.
- X74 (the dump): from time 0 to the check's mark (`vcd off` there), the run going on to the program's exit; a `when` can only turn the dump on at the mark's edge, a quarter cycle after the window opens.
- X76 (the timescale): each cut's `$timescale` 10ps in place of 1ps, so tb_bin's 1 ns run reads as one at 10 ns; X9's `CLOCK_NS`, PT's 10 ns clock and E_w = P_w · C_w · 10 ns hold unchanged.

No DECISIONS changes this round. PITFALLS: DC18 (an output port nothing loads stays with no driver), VS2 (a change to or from X is no toggle), and Q15 (the braces hold the whole `vcd add` word; the VCD's and SAIF's forms of an escaped scope).
