## Step 1: the cell models

From `NangateOpenCellLibrary.v` beside the nangate45 `.db` (`sim/pwr.py`'s `cell_model`: `RTL_flow_Nangate15/tech/nangate45/NangateOpenCellLibrary.v`). Both flops assign Q with `<=` in their posedge block: no stop.

```verilog
module CLKGATE_X1 (CK, E, GCK);
  input  CK, E;
  output GCK;
  reg    latch_en;
  always @(CK or E)
    if (~CK) latch_en <= E;
  assign GCK = CK & latch_en;
endmodule
module DFF_X1 (D, CK, Q, QN);
  input  D, CK;
  output reg Q, QN;
  always @(posedge CK) begin
    Q  <= (D);
    QN <= ~(D);
  end
endmodule
module DFFR_X1 (D, RN, CK, Q, QN);
  input  D, RN, CK;
  output reg Q, QN;
  always @(posedge CK or negedge RN) begin
    if (~RN) begin
      Q  <= 1'b0;
      QN <= 1'b1;
    end else begin
      Q  <= (D);
      QN <= ~(D);
    end
  end
endmodule
```

The ICG is a latch open while CK is low, then `GCK = CK & latch_en` as a continuous assignment: in a zero-delay run the gated clock rises in the same time step as CK, in the active region, before the flops' nonblocking updates land, so a gated flop samples the values from before the edge, as an ungated one does. Buffers and inverters are `assign`s too. Not a flop, not a stop, but noted: the library's latches `DLH_X1/X2` and `DLL_X1/X2` assign Q with `=`; DC's integrated gates do not use them.
