# PWR1 R2b run note (2026-11-12, micas-lapserv1)

**Result: averaged mode is kept for the cluster (no X77).** R2b ran windows `4_acc_config` (11 cycles, idle) and `5_run` (185 cycles) of `dot3_w16` in PrimePower's averaged and time-based modes. Averaged mode's idle clock, 44.5 mW in `acc_config`, matches the `.lib` hand count: 63,135 flops × about 7.1 fJ per cycle (a held DFFR_X1's clock pin, rise + fall: 3.17 + 3.98 fJ at D = Q = 0, 3.34 + 3.77 fJ at D = Q = 1) ≈ 44.8 mW. Time-based gives 21.1 mW for flops that hold. Combinational and the macros agree within 0.5 % between the modes; the whole difference is in the clock pins. The hypothesis in R2b's context (averaged mode undercounts toggling flops, Q and QN taken as independent) is not supported: time-based is lower, not higher, and lower most where the flops hold. The streamers' run energy below idle in averaged mode (149.8 against 154.2 pJ per cycle, R2) stays as measured.
