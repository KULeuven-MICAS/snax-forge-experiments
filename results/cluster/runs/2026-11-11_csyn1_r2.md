# Run note: CSYN1 Part B R2, the cluster source, step 1 (RTL with the memory macros), 11 Nov 2026

R2a (`ee2482e6`, tag `csyn1-partb-r2a`) wrote `cluster/mem.py`, the generated `tc_sram_impl.sv`, its test and its Verilator equivalence bench. This round builds step 1 of the cluster source (X67): `pixi run cluster rtl <point>` bundles a snax-forge design, builds snax_cluster's whole cluster around it, runs the bundle's ELF on the plain RTL and on the RTL with every memory as a RAM1 macro through X66's `tc_sram_impl.sv`, and checks both runs against each other and against snax-forge's own run (D123). The first point is `dot3_w16` (dot_3 at W = 16, N = 2048).

Both runs pass D123 (`forge data: 0 errors (1 words)`, `forge counter mult_dot: 132` against 132, fill 3), no X shows up, and the macro run's 828 cycles equal the plain run's and R1's baseline (SNAX-GVSoC: 818). Two things bit on the way (PITFALLS Q12, Q13); both are fixed in this round's code, with no change to snax_cluster.
