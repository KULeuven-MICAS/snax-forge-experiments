# Run note: CORE1 R4, the one-core cluster through the cluster flow (X67), 12 Nov 2026

CORE1 made snax-forge's base cluster one Snitch core that drives both the DMA and the accelerator (snax-forge D170); its R2 checked it on vsim. This round reruns CSYN1's cluster flow (X67) on `dot3_w16` (dot_3 at W = 16, N = 2048) with that cluster: the RTL with RAM1's macros, DC on the whole cluster, the netlist run, the quiet build (snax-forge D135) on the netlist, then the area breakdown and HWCOST (X72), for PWR1.

**Result:** every step passed. `cluster rtl`: PASS, 810 cycles (plain 810), 36 `tc_sram_impl` on 3 macros. `cluster syn`: ok, 1,261,630 µm² (macros 475,791 µm²), slack +1.232 ns at 10 ns, 0 errors, every gate passes. `cluster gls`: PASS, 810 cycles (rtl 810), swap ok, RAMCOUNT as CSYN1's (4 I-cache macros +1 write at reset). The quiet ELF on the netlist: `[SUCCESS]`, exit 0, no program output, 42 s of Questa. The cluster is 52,677 µm² (4.0 %) smaller than CSYN1's two-core one; HWCOST's five parts are within 0.1 % of their groups.

These rows replace CSYN1's two-core ones in place (`synth_dc.csv`, `reports/dot3_w16.zip`, `hwcost/dot3_w16.json`, `breakdown.json`); CSYN1's numbers are in git at `2cd0234` and in CSYN1's run notes (`2026-11-11_csyn1_r2.md` to `_r4.md`).

## Step 5: the quiet ELF on the netlist

`sw/forge_quiet.elf` of the bundle zip on step 2's netlist, set up as step 4's run: a script (outside the repos, using `cluster/cluster.py`'s own `Steps`, `unpack` and `cluster/mem.py`) unpacked the bundle zip and the netlist into `tmp/cluster/dot3_w16_quiet/`, ran rtl-gen and clustergen in the image, `mem.make` (its `tc_sram_impl.sv` equal to step 1's), then:

    make vsim_preparation CFG_OVERRIDE=$CFG $OPTS                      (image)
    make snax-forge-sim SIM=vsim CFG_OVERRIDE=$CFG $OPTS               (host)
    make snax-forge-run SIM=vsim CFG_OVERRIDE=$CFG ELF=<work>/sw/forge_quiet.elf $OPTS   (host)

with `OPTS` = `SRAM_IMPL=<work>/mem/tc_sram_impl.sv SRAM_MODELS=<work>/mem/sram_models.f SIM_TYPE=gate_level_sim GLS_NETLIST=<work>/netlist/snax_forge_cluster_wrapper_mapped.v GLS_CELLS=<NangateOpenCellLibrary.v>`, as `cluster gls`. snax_cluster's vsim script takes the quiet ELF as it takes `forge.elf` (`ELF=`); no hand vsim command and no change to snax_cluster. Then the work folder was deleted and `make clean-vsim clean-generated` ran (snax_cluster clean).

Result: `[SUCCESS] Program finished successfully` at 2,200 ns, `snax-forge-run` exit 0. The program printed nothing: the only lines that are not Questa's are fesvr's three boot lines. The netlist also printed its 36 RAMCOUNT lines. Time: the run 42 s of Questa's elapsed time (43 s step; `forge.elf` 48 s), the netlist build 74 s, the whole setup 187 s; `vsim.wlf` from `VSIM_FLAGS`' `log -r /*` was 46 MB (deleted). PWR1's VCD dump comes on top of that run.
