# Run note: CSYN1 Part B R3, the cluster source, step 2 (DC on the whole cluster), 11 Nov 2026

R2 (`2026-11-11_csyn1_r2.md`, tag `csyn1-partb-r2`) built step 1, the cluster's RTL with every memory as a RAM1 macro. This round builds step 2 of the cluster source (X67): `pixi run cluster syn <point>` runs Design Compiler on the whole `snax_forge_cluster_wrapper`, from snax_cluster's own synthesis list (`make gen-syn`), with X66's `tc_sram_impl.sv` and the macros linked, X68's constraints and no SDF (X69). The first point is `dot3_w16` (dot_3 at W = 16, N = 2048).

**Result:** `cluster syn dot3_w16: ok`, total area 1,314,306 um2, of which the 36 macros 475,791 um2; worst slack +1.442 ns at 10 ns (reg2reg, a Snitch core's `pc_q` to `instret_q`); 0 errors; every gate passes. Getting there took a snax_cluster fix: its synthesis list had no iDMA (snax_cluster #693, merged as main `7c14681c`, PITFALLS SC10).
