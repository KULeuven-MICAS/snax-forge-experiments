## Choices made here

- $C_\text{run}$ for $\eta_A$ is the plain RTL run's `cycles run` (core 0's `mcycle` between the barriers that also bound the quiet build's run window), so every run has one, power or not; the window's cycles are listed beside it, and $E_\text{run}$ uses the window's own.
- `snb gls` and `snb pwr` refuse a netlist whose sha256 is not the config's in `snb_points.json`; a new DC run prints the value to set there.
- Every run uses its own do-file in place of VSIM_FLAGS' `log -r /*`: no waveform log, RTL or netlist.
- A new ELF in `snb rtl` empties the run's netlist columns in `runs.csv`.
- Leakage is left out of E11's report for now (Ryan, X92); PT's reports keep it.
