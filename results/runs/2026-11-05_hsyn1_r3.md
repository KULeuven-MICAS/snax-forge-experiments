# Run note: HSYN1 R3, the bambu and xls synthesis sources, path-class slacks, Bambu's split, the cycle import, and the clean-up, 5 Nov 2026

Code and docs only: no DC, Questa or PT run (R4 probes synthesis on three points). `syn.py` gets the `bambu` and `xls` sources next to `hls` (Vitis), with case filters, `MAX_W = 16`, a clock and reset port guard and `check-ports`; `dc_syn.tcl` measures four path-class slacks after compile; Bambu rows get a control/datapath split; the Bambu and XLS cycle CSVs are imported with their provenance; SYN1's and SYN2's analysis code and results are deleted. Decisions X38 to X43.

**Every check passes:** `list` gives hls 60, bambu 40 and xls 40 points; `check-ports` passes on all 140; the guard fails as it should when a Bambu point is given Vitis's ports.
