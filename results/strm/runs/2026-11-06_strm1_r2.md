# Run note: STRM1 R2, the interconnect's energy interpolated in 1/inputs, 6 Nov 2026

R1's leave-one-out check showed the interconnect's energy per access overestimated by 11 to 24 % at 8 and 16 inputs when interpolated linearly in inputs. At a fixed bank count it goes as $a + b/n$ (a per-cycle cost shared by the grants), so R2 interpolates it in 1/inputs (X54, replacing X53's rule for that field) and documents every interpolation rule step by step with worked examples (`docs/cost_tables.md`). Python only, no EDA tool: done in Claude's sandbox on R1's committed tables, which `pixi run strm-table` rewrote byte-identically.

## Changes

- `report/strm_table.py`: a per-field, per-axis scale (`SCALES`, `XBAR_SCALES`): the interconnect's `e_access_pj` takes its weight in 1/inputs; everything else stays linear in the raw values. The leave-one-out check uses the same scales.
- `report/test_strm_table.py`: a seventh test, `a + b/inputs` reproduced exactly anywhere inside the grid while the area stays linear in inputs.
- `docs/cost_tables.md` (new), X54, the X53 pointer, `docs/README.md`.

## Leave-one-out, interconnect energy (11 interior points with both neighbours measured)

| Rule | Mean | Worst |
|---|---|---|
| Linear in inputs (X53) | 8.98 % | +24.32 % (8, 64) |
| Linear in 1/inputs (X54) | 2.49 % | +11.32 % (32, 64); all others within 3.9 % |

Per point, in 1/inputs: 8×16 +1.0, 8×32 −1.1, 16×32 +2.7, 24×32 −2.3, 8×64 −0.1, 16×64 0.0, 24×64 −2.9, 32×64 +11.3, 40×64 −3.9, 48×64 +0.4, 56×64 +1.6 %. The reader's and the interconnect area's checks are unchanged from R1.

## Fitted forms, for comparison

Each fitted per bank count with `scipy.optimize.curve_fit` (scipy 1.18.1) on the measured points, then the same leave-one-out (refit without the point, predict it); the scratch script is not committed.

| Form | Parameters | Max residual on all points, 16 / 32 / 64 banks | Leave-one-out mean / worst |
|---|---|---|---|
| $a + b/n$ | 2 | 0.7 / 1.5 / 13.1 % | 4.6 / +15.1 % |
| $a + b/n + c\thinspace n$ | 3 | 0.0 / 1.5 / 8.9 % | 2.7 / +10.8 % |
| $k\thinspace n^p$ | 2 | 3.7 / 6.9 / 20.2 % | 11.1 / +18.5 % |
| $a + k\thinspace n^p$ | 3 | 0.0 / 1.5 / 12.9 % | 4.5 / +14.9 % |
| $a + b\thinspace e^{-n/\tau}$ | 3 | 0.0 / 3.4 / 10.9 % | 5.9 / +21.9 % |
| $a + b\thinspace n + c\thinspace n^2$ | 3 | 0.0 / 10.4 / 19.1 % | 13.6 / +23.7 % |
| $a + b/n + c/n^2$ | 3 | 0.0 / 1.5 / 13.3 % | 5.0 / +15.3 % |

The 16-bank row has three measured points, so the three-parameter forms pass through them exactly (0.0 %) and cannot be checked there. $a + b/n$ per bank count: 16 banks $2.206 + 6.12/n$, 32 banks $2.344 + 13.02/n$, 64 banks $3.908 + 24.36/n$ (residuals at most 0.02, 0.05, 0.54 pJ). The 64-bank row dips at 32 inputs (4.13 pJ against about 4.6 on either side) and rises slowly from 40 to 64 inputs; the dip was not traced.
