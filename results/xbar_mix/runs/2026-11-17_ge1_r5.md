# Run note: GE1 R5, the energy's factor form by bank count, 17 Nov 2026

R4 powered the 18 `xbar_mix` points by input kind. This round turns them into the energy's factor form beside the area's (X93): one pair $g_{ro}(b)$, $g_{wo}(b)$ per bank count from the points with inputs = banks, read on `xbar.csv`'s $e_{access}(b, b)$. No server run: `pixi run xbar-kinds` and `pixi run char-export` in the chat's checkout.

**Result:** at 32 banks $g_{ro}$ = 0.331792 and $g_{wo}$ = 0.471583, so a reader's request costs 1.839 pJ and a writer's 1.455 pJ against 2.753 read-write. Priced so, dot 3's interconnect in the gated cluster's `run` window is 0.97, 0.99, 0.94 and 0.84 of the cluster at W = 2, 4, 8, 16 (it was 1.45, 1.48, 1.40, 1.26), and 0.83 at W = 32 from SNAX-GVSoC's requests.
