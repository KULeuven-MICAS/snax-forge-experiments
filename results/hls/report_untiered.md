# Results: tier untiered

Generated by hls-exercises' `bench/bench.py` from `hls_cycles.csv` and `hls_loops.csv` in this folder. Do not edit; rerun `python3 bench/bench.py report`.

- **cycles**: cosim latency (RTL simulation, Verilog), or the csynth estimate (marked `est`) when cosim did not run.
- **cyc/elem**: cycles divided by the elements the size names (n, or m x n).
- **overhead**: cycles minus the beats, elements / W: what a run costs beyond one beat per cycle. Compare it with forge's counter minus its beats.
- **vs unopt**: the unopt cycles at the same size, W and clock divided by this row's.
- **II**: the top's interval from csynth. The loop table below has each loop's II.
- **HLS clock**: the period Vitis scheduled for. It sets how deep the pipelines are; it is not a timing result. Timing comes from ASIC synthesis (snax-forge-experiments' `syn/`).
- **config**: the run-time pins the testbench drove (forge's loopCount and len). The size reaches the hardware only through them.
- **RTL**: the hardware point in `rtl/` and whether this size's Verilog is that folder's: `ref` (the first size, the reference), `yes` (identical apart from the latency comment), `renamed` (identical once Vitis's numbered net names are masked), or `no` (it differs, and has its own folder).
- **est. latency**: csynth's estimate; `?` where a loop bound is a run-time pin with no trip count given (the DaCe case).
