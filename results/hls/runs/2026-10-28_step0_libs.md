## Conclusion

**The library is the only cause.** With the same DC (Y-2026.03-SP2), the same RTL bytes and the same scripts apart from the driving-cell name, the gscl45nm probe reproduces the 27 Oct row and the nangate45 probe the 28 Oct row, every field to the printed digits. The area gap is cell size: the same 582 flops are 7.98 vs 4.52 each, and gscl45nm's 31-cell library needs 676 buf/inv against 104.

Constraint values whose meaning changes with the library's units:

| value | where | gscl45nm | nangate45 | nangate15 |
|---|---|---|---|---|
| `set_load 0.03` | constraints.sdc | 30 fF | **0.03 fF** (INV_X1 input is 1.70 fF) | **0.03 fF** |
| `set_max_transition 0.25` | constraints.sdc | 0.25 ns | 0.25 ns (library default 0.1985 ns) | **0.25 ps** |
| `create_clock -period $clock_ns` (10) | constraints.sdc | 10 ns | 10 ns | **10 ps** |
| `set_clock_uncertainty 0.1 / 0.02` | constraints.sdc | ns | ns | **ps** |
| `set_input_delay / set_output_delay 0.01` | constraints.sdc | ns | ns | **ps** |
| fallback `max_capacitance 10.0` | dc_syn.tcl | 10 pF | 10 fF (below INV_X1's own 60.73 fF; not reached: no zero pins) | 10 fF (same) |
| `set_max_fanout 32` | constraints.sdc | unitless, same | same | same |

So the 27 Oct and 28 Oct runs share a time scale but not a load: set_load fell 1000x with the switch. On nangate15, every time constraint would be read in ps, 1000x tighter, with no error. On the output side, syn.py's `crit_path_ns` and `slack_ns` would hold ps on nangate15, and leakage comes in pW there (syn.py keeps the unit string, so the power columns stay readable). Area is in each library's own unit and is comparable only within a library. Two more differences: nangate45 applies a wire-load model by default (`5K_hvratio_1_1`, zero net area, so it changes timing and switching power but not area); gscl45nm and nangate15 have none. gscl45nm's 7 zero-max-cap pins exist only there. nangate15's flops all have an async reset or set.

Stale text found along the way (not changed): syn.py's docstring gives the 15 nm path as `tech/nangate15/NangateOpenCellLibrary_typical.db`, a file that does not exist; dc_syn.tcl's header, the `# Get from the FreePDK45nm` comment in constraints.sdc and syn.py's RAM-parking message still name FreePDK45 / gscl45nm.
