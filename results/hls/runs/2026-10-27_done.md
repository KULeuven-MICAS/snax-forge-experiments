## DC at 10 ns: 35 points ok, 1 stopped

- **35 ok.** None violates timing: worst slack is 3.49 ns (`dot/opt_w4`, critical path 6.35 ns). `maxcap_nets` is 0 everywhere, and no run logged an `Error:` line.
- **`done/dot/dace_w1`: stopped by hand.** Its row in `synth_dc.csv` reads `skipped: needs a RAM macro (p_tmp0 64x512 1R1W); gscl45nm has none, generate one (OpenRAM)`. It is the only point with a RAM: DaCe's buffer `p_tmp0`, 64 bits × 512 entries, single port (`dot_dace_p_tmp0_RAM_AUTO_1R1W.v`, the BRAM_18K = 2 above). No other folder in `rtl/done/` instantiates a RAM. `gscl45nm` has no memory cells, so DC builds the RAM out of flops:

  ```
  141: Inferred memory devices in process in routine 'dot_dace_p_tmp0_RAM_AUTO_1R1W_DataWidth64_AddressWidth9_AddressRange512'
  153: | dot_dace_p_tmp0_RAM_AUTO_1R1W_DataWidth64_AddressWidth9_AddressRange512/46 |  512   |   64    |      9       |
  157: Module: dot_dace_p_tmp0_RAM_AUTO_1R1W_..., Registers: 32832, Async set/reset: 0, Sync set/reset: 0
  139: Warning: .../dot_dace_p_tmp0_RAM_AUTO_1R1W.v:31: The statements in initial blocks are ignored. (VER-281)
  ```

  Elaboration ran single-threaded from 09:34 to 09:48. `compile_ultra` was in Pass 1 mapping when the run was stopped at 09:51, with no `Error:` lines. A register file of that size is no fair area figure, so this point needs a real SRAM macro. FreePDK45 ships no memory compiler; OpenRAM supports FreePDK45 (`freepdk45` technology) and gives `.lib`, `.lef`, `.gds` and a Verilog model.

## Odd things

- **The pins are not registered at `ap_start`.** Plan section 2 says the top copies each pin into a local at entry. In the Verilog, Vitis compares the input port directly inside the loop, for example `vecadd/opt_w4/vecadd.v:326: icmp_ln9 = (ap_sig_allocacmp_b_1 == loop_count)`, and `vsum` and `dot` do the same with `loop_count` and `len`. Only `dot` `opt` registers `len` (`len_read_reg <= len`), and `dace` passes `loop_count[28:0]` into its sub-module. With `ap_none`, Vitis takes the port as stable for the whole run. Forge's `CtrlAdapter` samples at start, so the HLS tops leave out that 32-bit register and need the pins held for the whole run.
- `rtl/done/dot/dace_w1/` also holds `dot_dace_p_tmp0_RAM_AUTO_1R1W.dat`, the RAM's `$readmemh` init file. DC ignores it (VER-281).
- The `dace` rows' csynth latency is `?`, as the plan expects. `dot` `dace` shows `13-?`.
- `syn/syn-work/` is an empty folder left over from an earlier session. It is untracked, and I left it.
